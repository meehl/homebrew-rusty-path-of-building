# Rusty Path of Building Tap

A third-party Homebrew tap for [rusty-path-of-building](https://github.com/meehl/rusty-path-of-building).

# Installation instructions

## First, install this repository as a tap for homebrew

```shell
brew tap meehl/homebrew-rusty-path-of-building
brew trust meehl/rusty-path-of-building
```

## Now, you should be able to install it

```shell
brew install rusty-path-of-building
```
